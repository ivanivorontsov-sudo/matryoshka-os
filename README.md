# Матрёшка

**Матрёшка** — настольная система на базе Debian 13 (trixie) для компьютеров x86_64. Она объединяет KDE Plasma 6, запуск Windows-программ через Wine и Android-приложений через Waydroid, а также собственные инструменты для поиска, защиты, восстановления и интеграции приложений.

Главная идея проекта: **пользователь управляет компьютером, а не компьютер пользователем**. Сеть не включается сама по себе, автоматическая установка обновлений не подменяет решение владельца, а приватность заложена в конфигурацию, а не спрятана за рекламным обещанием.

> [!IMPORTANT]
> **Текущий последний выпуск обновления — 18.6.19.** Он исправляет ошибку `100000400` при входе в Zoom по ссылке. Последний установочный Live-образ ISO — **18.6.18**; после установки из него обновитесь до 18.6.19 через «Копия и обновление Матрёшки». Выпуск 18.6.19 — пакет обновления, а не новый ISO. [Открыть последний выпуск и материалы релиза](https://github.com/ivanivorontsov-sudo/matryoshka-os/releases/latest).

> [!WARNING]
> Матрёшка продолжает развиваться. Возможны недоработки и различия в поддержке оборудования. До установки сделайте проверенную резервную копию на отдельный носитель, внимательно проверьте разметку диска и отдельно оцените необходимость шифрования. См. [предупреждение перед установкой](docs/INSTALLATION-WARNING.md).

## Приватность и сеть

В штатной конфигурации установленной системы сетевое подключение по умолчанию отключено (NetworkingEnabled=false). Пользователь может включить его кнопкой в «СуперСмарте», ярлыком «Сеть вкл/выкл» или переключателем в системном трее.

В конфигурации системы отключены или исключены из состава, в частности:

- popularity-contest, avahi, cups-browsed, geoclue, ModemManager, PackageKit и Discover;
- таймеры apt-daily; автоматическая установка обновлений через unattended-upgrades не используется;
- телеметрия KDE и перечисленные в политиках Firefox ESR механизмы вроде Telemetry, Studies и Pocket.

При включённой сети предусмотрены фоновые сценарии обновления баз антивируса и поиска драйверов. Их можно отключить настройками. Это не означает, что интернет доступен только этим двум сценариям: после включения сети пользователь может сам запускать браузер и любые другие сетевые приложения. OpenSnitch и межсетевой экран дают средства для контроля сетевой активности программ.

Описана штатная конфигурация. Установленные пользователем приложения, расширения, изменённые политики и дополнительные службы могут обращаться к сети независимо от настроек Матрёшки.

## Загрузка: BIOS/Legacy, UEFI и Secure Boot

Здесь важно учитывать конкретный носитель и выпуск:

- **Live-образ 18.6.18:** загружается только в режиме BIOS/Legacy (CSM). Загрузка этого образа в UEFI не поддерживается. На компьютере без Legacy/CSM запустить этот Live-носитель не получится.
- **Установка:** Calamares включает проверки EFI и в составе проекта присутствует shim-signed. Это сведения о компонентах и проверках установщика, а не доказательство того, что Live-образ загружается в UEFI или что Secure Boot гарантированно работает на любом устройстве.
- **Secure Boot и внешние модули:** для DKMS-модулей при включённом Secure Boot может понадобиться подпись модуля и регистрация пользовательского ключа MOK. Наличие shim-signed само по себе не подписывает сторонние модули и не гарантирует их загрузку.

Не отключайте Secure Boot и не переключайте режим прошивки без понимания последствий. Перед установкой проверьте примечания именно к тому ISO и обновлению, которые собираетесь использовать.

## Обновления и восстановление

Матрёшка не устанавливает системные обновления автоматически через unattended-upgrades: пользователь сам выбирает, когда обновлять систему. Перед обновлением рекомендуется создать резервную копию.

В установленной системе при соответствующей схеме разделов могут использоваться Btrfs и Snapper для снимков и отката. Restic предназначен для резервного копирования. Снимок системы не заменяет отдельную копию личных файлов: храните важные данные на другом физическом носителе или в надёжном хранилище.

## Windows в виртуальной машине

Матрёшка умеет создавать виртуальную машину из ISO и загружать официальный образ Windows с сайта Microsoft. Внутри виртуальной машины доступ в интернет работает по её собственной конфигурации.

> [!IMPORTANT]
> Для установки и использования Windows требуется действительная лицензия Microsoft. Активаторы и средства обхода лицензирования не входят в Матрёшку и не рекомендуются. Загружайте Windows с официального сайта Microsoft и проверяйте контрольную сумму образа.

## Сборка

Сборка выполняется на Debian 13 официальным инструментом Debian live-build:

~~~bash
./build.sh
~~~

Скрипт устанавливает инструменты сборки, получает внешние компоненты и исходные материалы, подготавливает файлы образа и запускает lb build. Поэтому сборочной машине требуется интернет, права администратора и достаточно свободного места. Сетевое поведение сборочной машины не следует путать с настройками готовой установленной системы.

Готовые образы и пакеты обновления публикуются в [Releases](https://github.com/ivanivorontsov-sudo/matryoshka-os/releases). Перед установкой проверяйте контрольные суммы и подписи опубликованных файлов по инструкциям соответствующего выпуска.
