# Матрёшка

> [!CAUTION]
> **Весь код Матрёшки написан ИИ, за исключением сторонних открытых компонентов.** Возможны ошибки. Используйте на свой риск и перед установкой или обновлением делайте резервные копии важных файлов.

> [!WARNING]
> **Матрёшка ещё развивается:** в системе могут оставаться небольшие недоработки. Перед установкой обязательно сохраните все важные файлы на отдельный носитель, внимательно проверьте разметку и форматирование диска, а также отдельно оцените необходимость шифрования. Подробности: [предупреждение перед установкой](docs/INSTALLATION-WARNING.md) и [дополнение к выпуску 18.5](docs/RELEASE-NOTES-18.5.md).

Преемница «Читалки OS 2». Живая флешка на Debian 13 (trixie) для x86_64. Образ 18.6.3 загружается только в режиме BIOS/Legacy (CSM); загрузка в UEFI с этого образа не поддерживается. Последний выпуск — 18.6.10 (заметки: `docs/RELEASE-NOTES-18.6.10.md`). **После установки системы с образа 18.6.5 обязательно обновитесь до 18.6.10** через «Копия и обновление Матрёшки». Собирается официальным инструментом Debian `live-build`, а своего кода в ней минимум: только «клей» на Python и PyQt6 в `config/includes.chroot_after_packages/usr/lib/matryoshka`.

## Приватность
- Сеть по умолчанию выключена (`NetworkingEnabled=false`). Включается одной кнопкой: в СуперСмарте, через ярлык «Сеть вкл/выкл» или переключатель в трее.
- Проверка подключения в NetworkManager отключена. Нет popularity-contest, avahi, cups-browsed, geoclue, ModemManager, PackageKit и Discover, unattended-upgrades. Таймеры apt-daily замаскированы.
- Телеметрия KDE отключена. Firefox ESR закрыт политиками: без телеметрии, исследований, Pocket, Safe Browsing и проверки портала.
- В сеть ходят только две вещи, и только когда сеть включена: обновление баз антивируса и поиск драйверов. Это отключается флажком.

## Windows в виртуальной машине
Матрёшка умеет создать виртуальную машину из любого своего образа ISO и скачать официальный образ Windows с сайта Microsoft. Внутри машины обычный доступ в интернет.

> [!IMPORTANT]
> Для установки и использования Windows нужна действительная лицензия Microsoft. Активаторы и другие средства обхода лицензии запрещены и в Матрёшку не входят. Скачивайте Windows только с сайта Microsoft и сверяйте SHA-256 образа с опубликованным Microsoft.

## Боли современных ОС и как их решает Матрёшка
| Боль | Решение (готовое) |
|---|---|
| Принудительные обновления и перезагрузки | apt-daily и unattended-upgrades отключены, обновляет только сам пользователь |
| Реклама и «рекомендации» в системе | KDE без рекламы, Firefox с политиками, блокировка трекеров списком StevenBlack hosts |
| Телеметрия | нет popularity-contest, KUserFeedback выключен, Firefox Telemetry выключен, сеть по умолчанию выключена, OpenSnitch показывает каждую попытку выхода в сеть |
| Мусорные предустановки | только нужные пакеты, без apt recommends |
| Обязательная учётная запись | только локальный пользователь, пароль можно оставить пустым |
| Ад драйверов | ядро и прошивки Debian, isenkram подбирает пакеты под железо, fwupd по согласию |
| Плохой поиск | KRunner, FSearch (как Everything), поиск СуперСмарта с транслитом и исправлением раскладки |
| Обновление сломало систему | снимки Btrfs + Snapper, режим восстановления, обнаружение неудачной загрузки |
| Медленная загрузка | минимум служб, простой режим без анимаций |
| Вирусы и сомнительные файлы | ClamAV + YARA, Песочница (одноразовая ВМ), Firejail |
| Нельзя запустить программы для другой системы | Wine (exe), DOSBox-X (DOS), Waydroid (apk/xapk), QEMU (любая ОС) |
| Не хватает места | «Бесконечная память»: rclone union + crypt по нескольким облакам |

## Чего обычно нет «из коробки», а здесь есть
Громкость для каждого приложения (plasma-pa), эквалайзер (EasyEffects), файловый менеджер с вкладками и двумя панелями (Dolphin, F3), межсетевой экран с интерфейсом (ufw + plasma-firewall), блокировка сети для отдельных программ (OpenSnitch), блокировка рекламы через hosts, поиск дубликатов (rmlint-gui), автозапуск (Параметры системы), предел заряда батареи (PowerDevil), версии файлов (снимки Snapper), зашифрованные сейфы (Plasma Vault + gocryptfs/cryfs), карты (Marble), русская проверка орфографии (hunspell-ru), связь с телефоном (KDE Connect), закрепление окна поверх остальных (KWin), заметки (виджет «Заметки»), история буфера обмена (Klipper, Meta+V), пипетка (KColorChooser), запись экрана и скриншоты (Spectacle, Flameshot), текст с экрана (OCR через Tesseract), плитки окон (KWin, Meta+T), массовое переименование (KRename), занятость диска (Filelight, QDirStat), разделы (GParted, KDE Partition Manager), кодеки (GStreamer, FFmpeg, VLC), работа с PDF (PDF Arranger, Okular), любые архивы (Ark + 7-Zip с RAR, unrar, bsdtar, zstd, lz4, lzip, cabextract, arj, lha, squashfs).
