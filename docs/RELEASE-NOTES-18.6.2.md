# Матрёшка 18.6.2 (предварительный выпуск)

> Перед обновлением сделайте или выберите резервную копию в «Копия и обновление Матрёшки». Это предварительный выпуск: многое проверено только в сборочной среде, без ноутбука. Ниже у каждого пункта честно написано, что проверено.

Входит всё из 18.6.1 и исправления, собранные после него.

## Как обновиться

Репозиторий закрытый, поэтому проверка обновлений в Центре этот выпуск не видит. Обновляйтесь вручную.

1. Войдите в GitHub в браузере и скачайте из этого выпуска в папку `~/Загрузки` файлы: `matryoshka-update-18.6.2.tar.gz`, `matryoshka-update-18.6.2.tar.gz.sha256`, `matryoshka-update-18.6.2.tar.gz.sig`, `SHA256SUMS`, `SHA256SUMS.asc`. Если браузер добавил к имени « (1)», переименуйте файл.

2. Проверьте подпись и контрольные суммы:

```
cd ~/Загрузки
G=$(mktemp -d)
gpg --homedir "$G" -q --import /usr/share/matryoshka/update-keys/matryoshka-release.gpg
gpg --homedir "$G" --verify SHA256SUMS.asc SHA256SUMS
gpg --homedir "$G" --verify matryoshka-update-18.6.2.tar.gz.sig matryoshka-update-18.6.2.tar.gz
rm -rf "$G"
sha256sum -c --ignore-missing SHA256SUMS
```

Обе проверки gpg должны написать «Good signature from "Matryoshka OS Release"» (по-русски «Действительная подпись»), отпечаток ключа `4532 8D5C 7182 16A0 9728 0102 45A2 D53B 7751 F4A8`. `sha256sum` должен написать `OK` для трёх файлов. Если что-то не совпало, не обновляйтесь. Предупреждение «ключ не заверен доверенной подписью» — нормально.

3. Проверьте, что стоит программа обновления 1.1.0:

```
dpkg-query -W matryoshka-upgrade
```

Если её нет или версия ниже 1.1.0, скачайте из выпуска `matryoshka-upgrade_1.1.0_all.deb` и выполните `sudo apt install ~/Загрузки/matryoshka-upgrade_1.1.0_all.deb`.

4. Обновление тем же путём, что и в программе обновления. Запустите «Копия и обновление Матрёшки» (`matryoshka-upgrade`). На шаге 1 сделайте копию. На шаге 2 выберите `~/Загрузки/matryoshka-update-18.6.2.tar.gz`, SHA256 подставится сам из файла `.sha256`. Нажмите «Обновить» и после окончания перезагрузите компьютер.

То же самое из терминала:

```
sudo bash /usr/lib/matryoshka-upgrade/sysbackup.sh plan same
sudo bash /usr/lib/matryoshka-upgrade/sysbackup.sh create same
sudo bash /usr/lib/matryoshka-upgrade/upgrade.sh ~/Загрузки/matryoshka-update-18.6.2.tar.gz "$(cut -d' ' -f1 ~/Загрузки/matryoshka-update-18.6.2.tar.gz.sha256)" same
sudo reboot
```

`plan` показывает, хватает ли места для копии. `create` делает копию (без неё `upgrade.sh` не запустится). Копию лучше делать на другой диск: вместо `same` укажите папку на нём.

## Отпечаток пальца (Goodix GXFP5130), matryoshka-gxfp 0.1.11

- Снимки декодируются верно: порядок точек `col`. Это подтвердили картинки со снимками с ноутбука.
- По умолчанию снимок идёт в сравнение без фильтра. С фильтром фона (0.1.9) совпадений на ноутбуке стало меньше. Включить фильтр снова: `sudo matryoshka-gxfp prep hp`.
- Отпечаток принимается, если лучшая оценка не ниже 12 или сумма трёх лучших оценок по шаблонам не ниже 20. Раньше считалась только лучшая оценка.
- При записи 24 касания вместо 16, чтобы покрыть больше площади пальца маленьким сенсором.
- Формат отпечатков сменился. После обновления появится уведомление: отпечатки нужно удалить и добавить заново.
- Сброс сканера после ошибки и после сна не перезапускает fprintd во время проверки пальца.

**Не проверено на ноутбуке.** Методы сравнивались на открытой базе отпечатков (вырезки 64×80), а не на снимках с этого сенсора. Корреляция и масштабирование оказались хуже SIGFM. Насколько часто палец будет узнаваться на самом ноутбуке, пока неизвестно. Проверка чужим пальцем на ноутбуке тоже не делалась. Пароль работает всегда.

## Вход по лицу

- Экран блокировки читает файл лица от имени пользователя. Теперь файл принадлежит root и группе пользователя с правами 640, каталог моделей имеет права 755. Права исправляются при обновлении и после каждой записи лица. matryoshka-face 1.0.7.
- В Параметрах системы рядом с «Пользователями» есть пункт «Вход по лицу»: записать, проверить, удалить лицо, а также включить его для экрана блокировки.

Права проверены в сборке. Разблокировка лицом на ноутбуке не проверена.

## Рабочий стол и меню

- **Значки на панели задач** (жёлтая «W» вместо значков Firefox, Konsole и других): при первом входе после обновления кэш меню KDE и значков пересобирается, у файлов кэша в домашней папке возвращается владелец. На ноутбуке не проверено.
- **«Удалить» в меню «Пуск»:** пункт «Удалить или изменить дополнения» открывает окно Матрёшки. Окно находит пакет программы и удаляет его через apt-get remove (без purge). Системные и защищённые пакеты удалить нельзя, окно скажет об этом. Android-приложения удаляются через Waydroid.
- **Android-приложения в меню:** пункт «Настройки приложения» по-русски, есть «Удалить». Старые ярлыки исправляются при входе.
- **Discover, «не найдено в репозиториях»:** после загрузки служба `matryoshka-appstream` один раз скачивает каталог программ Debian (AppStream), если его нет. Проверено в сборочной среде: после загрузки каталога Konsole, Dolphin и Firefox находятся. Сам Discover на ноутбуке не проверен.
- **Значок на рабочем столе для новых программ** (Debian, Flatpak, Android) появляется сам. Выключается в Центре.
- **Центр Матрёшки:** свой значок (матрёшка с шестерёнкой). Колесо мыши больше не меняет значения в списках, счётчиках и ползунках, пока на них нет фокуса, а прокручивает страницу. Проверено в тесте Qt.
- **KRunner:** у поиска Матрёшки есть метод Config, ошибка в журнале KRunner пропала.
- **«О системе»:** «Матрёшка 18.6.2 (на базе Debian 13)», логотип, сайт и адрес для сообщений об ошибках. Имя загрузчика не меняется.

## Клавиши копирования

Схема «Windows» по умолчанию: Ctrl+Insert копирует, Shift+Insert вставляет, Shift+Delete вырезает. Это работает и в Konsole, Ctrl+Shift+C/V остаются. В Центре можно выбрать схему «Windows», «как в macOS» или «Linux». Свои сочетания пользователя не перезаписываются. Проверено на файлах настроек. Konsole на ноутбуке не проверена.

## DOS

Папки и программы с русскими именами открываются через латинские ссылки, поэтому Norton Commander в папке с русским именем находится. Сообщения mount скрыты, приветственного экрана DOSBox-X нет. Проверено в DOSBox-X в сборочной среде.

## Звук

Улучшение звука, которое раньше включалось только после открытия «Матрёшка Звук», теперь включается само. Easy Effects запускается при входе отдельной службой и применяет последний профиль. Профиль ставится заново после сна и при подключении нового устройства. Громкость пользователя не меняется. На ноутбуке не проверено.

## Программы Windows (Wine) и «Кадр»

- Эмодзи в Electron под Wine больше не показываются квадратиками: в каждый префикс ставится монохромный шрифт Symbola под именем Segoe UI Emoji. matryoshka-fixes 1.1.6. Проверено с «Кадром» под Wine в сборочной среде.
- Программы Electron распознаются и запускаются без GPU. Имя компьютера записывается в /etc/hosts, ставится winbind (ntlm_auth).
- Пустая главная область «Кадра» после запуска — особенность самой программы: пока не выбран шаг, область пустая. Так же это выглядит и в Windows.

## Драйверы

При обновлении ставятся прошивки и драйверы из официальных репозиториев Debian 13 (main, contrib, non-free-firmware): Wi-Fi, Bluetooth, звук SOF, видео AMD и Intel (VA-API), печать, сканеры по USB, датчики. firmware-ipw2x00 и firmware-ivtv при обновлении не ставятся, потому что требуют вручную принять лицензию.

## Безопасность

- admin-run проверяет согласие только для активного местного сеанса пользователя, а не для первого сеанса в списке.
- VPN-клиентов и прокси в составе Матрёшки нет. Программы, которые вы поставили сами, обновление не удаляет.

## Не вошло

- **«Тихо щит»** не входит. В нём есть исходящий WireGuard-туннель по импортированному файлу .conf (WgUpstream). Он выключен по умолчанию, но через него трафик может уходить на удалённый сервер. Это противоречит условию «только локальная фильтрация». Решение за автором.
- Браузер «Тихо» поставляется только в образе ISO. Обновление его не трогает.
- Образа ISO 18.6.2 пока нет.
