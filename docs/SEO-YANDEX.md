# SEO для Яндекса — Matryoshka OS

Этот документ описывает уже настроенные механизмы и оставшийся шаг активации IndexNow.

## Что настроено в сайте

- Отдельные русские и английские URL; языковые альтернативы `hreflang`.
- Уникальные `title` и `description` на каждой из восьми страниц.
- Canonical URL, открытые для индексации метатеги robots и sitemap.xml.
- Читаемые адреса разделов: `/features/`, `/download/`, `/installation/`.
- JSON-LD Schema.org; на внутренних страницах добавлена разметка BreadcrumbList.
- Адаптивная навигация для узких экранов и SVG favicon.
- В GitHub Actions предусмотрена автоматическая отправка обновлённых URL через IndexNow.

## Включить IndexNow

1. Сгенерируйте ключ длиной 8–128 символов. Допустимы латинские буквы, цифры и дефис.
2. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**.
3. Создайте secret с точным именем `INDEXNOW_KEY` и вставьте туда ключ.
4. Запустите workflow **Deploy Matryoshka site to GitHub Pages** через **Actions → Run workflow** либо внесите следующее изменение в сайт.

При публикации workflow автоматически создаст файл проверки ключа в корне сайта и отправит восемь URL на `https://yandex.com/indexnow`. Если secret не задан, шаг IndexNow будет пропущен, а обычная публикация сайта продолжит работать.

Код ответа IndexNow 200 означает, что URL переданы. 202 означает, что ключ ожидает проверки. Передача URL не гарантирует их индексацию.

## Яндекс Вебмастер

Добавьте сайт `https://ivanivorontsov-sudo.github.io/matryoshka-os/` в [Яндекс Вебмастер](https://webmaster.yandex.ru/), подтвердите права и добавьте Sitemap:

`https://ivanivorontsov-sudo.github.io/matryoshka-os/sitemap.xml`

Затем проверьте robots.txt, мобильное отображение и статусы восьми важных URL. Используйте «Переобход страниц» для адресов, которые нужно отдельно попросить проверить. Статусы индексирования, запросы, показы и CTR можно достоверно оценить только в самом Вебмастере.
