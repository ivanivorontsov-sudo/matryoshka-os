
## Zoom
- `matryoshka zoom-doctor` проверяет установку Zoom из tar.xz, библиотеки, ссылки zoommtg://, часы, DNS, TLS, /etc/hosts, ufw, OpenSnitch, прокси, права на ~/.zoom, zoomus.conf и Wayland.
- `--fix` исправляет найденное, `--reset-cache` переносит ~/.zoom в резервную копию, `--test` открывает тестовую встречу Zoom, `--update` ставит свежий клиент, `--code 100000400` объясняет ошибку.
- Ярлык Zoom запускает клиент через xcb (QT_QPA_PLATFORM=xcb).

## Звук
- pactl читается в английской локали: в русской системе раньше не распознавались порты и события, из-за этого не запоминалась громкость наушников и не срабатывала пауза при отключении.
- Виртуальные устройства Easy Effects и неработающие порты больше не становятся устройствами по умолчанию для браузеров. Ручной выбор пользователя сохраняется.

## Антивирус перед запуском
- Программы из домашней папки, флешек и загрузок (AppImage, .deb, .exe/.msi, ELF, архивы с программами) проверяются ClamAV перед первым запуском. Результат запоминается по пути, размеру и времени изменения, повторный запуск мгновенный.
- Системные файлы из /usr, /opt и пакетов не проверяются. Терминал не затронут. Если движок не ответил, запуск не блокируется, показывается предупреждение.
- ClamAV (около 1 ГБ памяти) запускается по требованию через clamav-daemon.socket и останавливается после 30 минут простоя. Держать его включённым всегда: `sudo touch /var/lib/matryoshka/clamd-always` и `sudo systemctl enable --now clamav-daemon`.
- Ограничение: программу с битом исполнения, запущенную прямо из Dolphin, KDE запускает сам, без обработчика Матрёшки. Такие файлы проверяет страж папок при скачивании.

## Архивы с программами
- Двойной щелчок по tar.gz/tar.xz с программой: проверка ClamAV, затем установка в /opt/<имя> со значком в меню и командой в терминале. «Только для меня» ставит в ~/Программы. При угрозе установка запрещена. Архив без программы открывается в Ark.
