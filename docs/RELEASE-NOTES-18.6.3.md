## Новый ключ подписи

Закрытый ключ прежнего ключа выпуска `45A2D53B7751F4A8` утерян. С 18.6.3 выпуски подписываются новым ключом Ed25519 `F2DE4F9355F9383D`, отпечаток `2E5A 892C 35E1 9C67 AE66  0FB5 F2DE 4F93 55F9 383D` («Matryoshka OS Release 2026-11»). Открытый ключ входит в обновление (`/usr/share/matryoshka/update-keys/matryoshka-release-2026-11.gpg`), прежний ключ остаётся, старые подписи проверяются.

В установленной 18.6.2 нового ключа ещё нет. Поэтому автоматическая загрузка в 18.6.2 отклонит подпись `.sig` этого выпуска. Обновляйтесь из файла: скачайте архив и выберите его в «Копия и обновление Матрёшки». Не кладите файл `matryoshka-update-18.6.3.tar.gz.sig` в ту же папку, что и архив: 18.6.2 найдёт его рядом, проверит старым ключом и откажется обновляться. Подпись проверяйте отдельно, в другой папке. Проверить подпись вручную: `gpg --import matryoshka-release-2026-11.asc && gpg --verify SHA256SUMS.asc SHA256SUMS`.

## Образ ISO

`matryoshka-18.6.3-amd64.iso` (4,1 ГБ) выложен тремя частями: `matryoshka-18.6.3-amd64.iso.part00`, `part01`, `part02`. Скачайте все три части, `join.sh` и `SHA256SUMS` в одну папку и выполните `sh join.sh`: части склеятся в ISO, суммы проверятся. Записать на флешку можно Rufus (режим DD), balenaEtcher или `dd`.

В образе всё из 18.6.3: matryoshka-face 1.0.8, matryoshka-gxfp 0.1.12, matryoshka-fixes 1.1.6, «Тихо для ПК» 153.7.0, оба ключа обновлений, все исправления этого выпуска. Ядро прежнее, 6.12.115. Образ собран так же, как 18.6: система из образа 18.6 обновлена до 18.6.3, затем заново упакована. Сетевых клиентов VPN в образе нет; свои подключения можно добавить в «Параметры системы → Сеть».

Загрузка — как у 18.5: режим BIOS (Legacy/CSM). На компьютере только с UEFI включите в настройках CSM/Legacy.

Проверено: в QEMU (BIOS, программная эмуляция) образ загружается до сеанса Plasma живой системы; после простоя появился экран блокировки Матрёшки. Рабочий стол после разблокировки, установка с образа и загрузка на ноутбуке не проверялись.

Исходный код этого выпуска: `matryoshka-os-18.6.3-src.tar.gz`.

Входит всё из 18.6.2 и исправления после него.

## Как обновиться

1. Если «Копия и обновление Матрёшки» ещё не стоит: скачайте `matryoshka-upgrade_1.1.0_all.deb` и выполните `sudo apt install ./matryoshka-upgrade_1.1.0_all.deb`.
2. Скачайте `matryoshka-update-18.6.3.tar.gz` и `matryoshka-update-18.6.3.tar.gz.sha256` в одну папку.
3. Проверьте файл: `sha256sum -c matryoshka-update-18.6.3.tar.gz.sha256` (должно быть «OK»). Подпись: `gpg --import matryoshka-release-2026-11.asc && gpg --verify matryoshka-update-18.6.3.tar.gz.sig matryoshka-update-18.6.3.tar.gz` (Good signature, ключ F2DE4F9355F9383D).
4. В «Копия и обновление Матрёшки»: шаг 1 — копия, шаг 2 — выберите архив.
5. Перезагрузите компьютер.

Пакеты matryoshka-face 1.0.8, matryoshka-gxfp 0.1.12 и браузер «Тихо» 153.7.0 уже лежат внутри архива, отдельно их скачивать не нужно.

## Что сделано и что проверено

### Программы пользователя (P0)
Служба из 18.6.2, удалявшая сетевые программы пользователя, убрана и удаляется при обновлении. Программы, которые вы поставили сами, не удаляются. Проверено: служба и скрипт попадают в список удаления.

### Отпечаток пальца (P1), matryoshka-gxfp 0.1.12
Сравнение по умолчанию как в 0.1.8 (classic: совпадение одного снимка с порогом 12, 16 касаний). Вариант 0.1.11 включается командой `sudo matryoshka-gxfp matcher combined`. Модули для ядер 6.12.113–6.12.117, при установке нового ядра модуль собирается из исходников (нужны linux-headers-amd64, ставятся с обновлением). Пробные настройки откладываются, вернуть: `sudo matryoshka-gxfp tuning-restore`. **На ноутбуке не проверено.**

### Клавиши яркости и громкости (P2)
Свои сочетания KDE не стираются. Служба matryoshka-mediakeys меняет яркость и громкость сама, если рабочий стол не ответил за 0,6 с (выключить: `fallback=off` в /etc/matryoshka/mediakeys.conf). **На ноутбуке не проверено.**

### Звук (P3–P5)
Микрофон «Матрёшка Звук» больше не ставится по умолчанию сам. Виртуальные устройства и неработающие порты не становятся устройствами по умолчанию для браузеров, ручной выбор сохраняется. pactl читается в английской локали (в русской не распознавались порты). При переключении сеанса музыка ставится на паузу, карта отпускается; при отключении наушников пауза; громкость запоминается для каждого выхода. Проверено тестами разбора вывода pactl. **На ноутбуке не проверено.**

### Значки (P6), окно печати Okular (P8)
Неустановленная тема значков убирается один раз (копия .matryoshka-icons.bak), кэши пересобираются. Окно печати Okular поверх других окон: правило KWin добавляется один раз, свои правила сохраняются (копия kwinrulesrc.matryoshka.bak). Проверено на тестовых файлах настроек.

### Медленный выход из чёрного экрана (P7)
- Экран блокировки больше не перезапускает проверку лица и пальца каждые 10 секунд, пока он погашен (камера не занята при нажатии клавиши).
- Для Intel i915 выключен Panel Self Refresh через /etc/modprobe.d/matryoshka-i915.conf (`enable_psr=0`), командная строка ядра не меняется. Вернуть: удалить файл и выполнить `sudo update-initramfs -u`.
- Внешнему монитору всё равно нужно время на синхронизацию сигнала.
**На ноутбуке не проверено.**

### «Уют» при входе (P9)
Файла или раскладки с именем «уют» в системе нет. Всплывающее окно при новом сеансе, скорее всего, полноэкранная «домашняя» страница СуперСмарт (часы, поиск, плитки) или окно выбора стартового экрана. Теперь оба выключены по умолчанию, если вы сами их не выбирали. Включить снова: Центр → вид рабочего стола. **Предположение, на ноутбуке не проверено.**

### Быстрый скрин (P10), LibreOffice по-русски (P11)
Свой выбор области поверх готового снимка, Esc и правая кнопка отменяют. LibreOffice: язык документов русский, орфография на лету, словари переносов и тезауруса. Проверено в сборочной среде.

### Zoom (P12)
`matryoshka zoom-doctor` проверяет библиотеки, ссылки zoommtg://, часы, DNS, TLS, /etc/hosts, ufw, OpenSnitch, прокси, права на ~/.zoom, zoomus.conf и Wayland. `--fix` исправляет, `--reset-cache` переносит профиль в копию, `--code 100000400 --fix` сбрасывает профиль. Zoom запускается через xcb. Проверено: тестовая встреча Zoom открылась на сборочной машине. Ошибка 100000400 на ноутбуке не воспроизводилась.

### «Тихо щит» (P13)
«Тихо щит» — локальный фильтр рекламы. Код просмотрен. В обновление не входит.

### Диктофон (P14)
Запись через PipeWire в Opus, выбор микрофона (неработающие и виртуальные помечены), уровень, пауза, отмена, переименование. Проверено: запись 5,7 с на сборочной машине.

### Вход по лицу (P15, P16), matryoshka-face 1.0.8
- Если кадр слишком тёмный, он сначала осветляется, а не отбрасывается. Если обычная проверка не узнала лицо, делается вторая попытка на кадре с выровненной яркостью. Прежний путь проверки остаётся первым, порог узнавания не менялся.
- При записи лица к каждому ракурсу сохраняется второй снимок с поправкой света. Совет в окне: записать снимки ещё раз при плохом свете.
- «Вход по лицу» в меню программ (раздел Настройки) с действиями «Записать лицо ещё раз» и «Пользователи», в Параметрах системы рядом с «Пользователями» и в Центре.
Проверено на фотографии: при затемнении до 15 % расстояние до своего лица 3,91 → 2,86 (порог 3,5). **На камере ноутбука не проверено.** Две попытки чуть повышают вероятность принять похожего человека. Пароль работает всегда.

### «Бесконечная память» в трее (P17)
Значок в трее: открыть, подключить и отключить, свободное место, настройки. Проверено offscreen.

### Поиск по типам файлов (P18)
В Dolphin и окнах выбора файла (KDE и GTK) есть места «Картинки», «Видео», «Музыка», «Документы», «Архивы», «Программы», «Игры» с подпапками по источнику (Камера, Скриншоты, Загрузки и др.). Ссылки обновляются раз в 30 минут с низким приоритетом. Файл мест правится только целыми записями, с копией user-places.xbel.matryoshka.bak. Файловый менеджер по умолчанию выбирается в Центре. Проверено в сборочной среде.

### Архивы с программами и антивирус (P19)
- Двойной щелчок по tar.gz/tar.xz с программой: проверка ClamAV, установка в /opt/<имя> со значком и командой. Чужие папки в /opt и системные команды не занимаются (берётся имя с -2 или -app). При угрозе установка запрещена. Архив без программы открывается в Ark.
- Программы из домашней папки и загрузок проверяются ClamAV перед первым запуском, результат запоминается. Системные файлы и терминал не затронуты. Если движок не ответил, показывается предупреждение.
- ClamAV (около 1 ГБ памяти) запускается по требованию и останавливается после 30 минут простоя. Держать включённым: `sudo touch /var/lib/matryoshka/clamd-always` и `sudo systemctl enable --now clamav-daemon`.
Проверено в сборочной среде.

### DOSBox-X (P20)
Меню и сообщения по-русски (вывод TTF), кодировка 866, раскладка ru. Диск G: — рабочий стол. Для программы: «Добавить файл в папку программы» (обычное окно выбора файла) и «Открыть папку диска программы (C:)» в контекстном меню файла программы и ярлыка. KeyRus подключается сам, если положить его в ~/DOS/KEYRUS/KEYRUS.COM (в состав не входит). Проверено: DOSBox-X запущен на сборочной машине, меню по-русски. FreeDOS как отдельный слой не добавлен.

### Другие системы и Windows в окне (P21)
- «Свой ISO…» создаёт машину из любого образа на диске: Windows 11, 10/8.1, 7/Vista, XP и старше, Windows Server, Linux, BSD, ReactOS, DOS, Haiku или другая система. Тип угадывается по имени файла, его можно выбрать вручную.
- «Windows с сайта Microsoft» открывает официальную страницу загрузки Microsoft. Windows 10 и 11 можно скачать и через «Скачать и запустить» (quickget, серверы Microsoft). Других источников Windows нет.
- Перед Windows показывается предупреждение: нужна действующая лицензия, активаторы и «кряки» запрещены и не предлагаются, образ не с сайта Microsoft надо проверить. Матрёшка считает SHA-256 образа и просит сверить его с суммой Microsoft.
- Windows из своего ISO: сетевая карта Intel e1000 и диск IDE (работают без драйверов), для Windows 11 — 4 ГБ памяти и TPM. Внутри Windows обычный доступ в интернет: сеть QEMU user-mode (NAT), исходящие соединения TCP и UDP не ограничиваются.
- «Одноразово» начинает откатывать машину только после установки системы.
- С сайта Microsoft из России образ обычно не скачивается.
- Nox есть только для Windows и macOS, внутри виртуальной Windows он будет медленным. Для Android-приложений есть Waydroid.
Проверено: окно создания машины (выбор типа, предупреждение, SHA-256) в тесте Qt, параметры запуска QEMU (e1000, user-mode, IDE, TPM). Установка Windows и работа сети внутри неё не проверялись.
