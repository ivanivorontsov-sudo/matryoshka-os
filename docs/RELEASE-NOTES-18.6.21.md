# Матрёшка 18.6.21

> [!CAUTION]
> **Весь код Матрёшки написан ИИ, за исключением сторонних открытых компонентов.** Возможны ошибки. Используйте на свой риск и перед установкой или обновлением делайте резервные копии важных файлов.

Пакет обновления `matryoshka-update-18.6.21.tar.gz` ставится поверх 18.6.3–18.6.20 тем же способом, что и раньше: «Копия и обновление Матрёшки» (сначала резервная копия, затем архив и его SHA256). Новый образ ISO в этом выпуске не выкладывается: последний образ остаётся 18.6.18. В пакет входит всё из 18.6.20.

Пакет стал больше (около 400 МБ), потому что в нём лежат сами эмуляторы. Прошивки, образы IPSW, ROM и программы из магазинов в пакет не входят и не скачиваются.

## Программы других платформ

Новое окно «Программы других платформ» (меню, Центр → Программы, пункт «Запустить как программу другой платформы…» в контекстном меню Dolphin). Двойной щелчок по файлу сам выбирает нужный слой: `.ipa`, `.app`, `.dmg`, `.pkg`, `.jar`, `.jad`, `.sis`, `.sisx`, `.n-gage`, `.cab`, `.xap`, `.appx`. Для `.exe` Матрёшка смотрит заголовок: программы КПК (ARM, MIPS, SH, Windows CE) идут в PocketHLE, обычные программы Windows — как раньше.

| Платформа | Слой | Что умеет на самом деле |
|---|---|---|
| macOS | Darling 0.1.20260608, собран под Debian 13 | Командная строка macOS: программы для Intel x86-64 запускаются. Окна Cocoa создаются, но в нашей проверке их содержимое не рисовалось (чёрное окно). Программы только для Apple ARM не запускаются. |
| iPhone, старые игры | touchHLE 0.3.0 | 32-битные игры iPhone OS 2–4 в расшифрованном виде. 64-битные и зашифрованные из магазина не запускаются, Матрёшка объясняет причину. |
| iPhone, полная эмуляция | Inferno (ChefKiss), эксперимент | Эмуляция iPhone 11 целиком. Нужны ваш IPSW с серверов Apple и ключ SEP. Без ускорения работает очень медленно. |
| Java кнопочных телефонов | FreeJ2ME-Plus 1.53 | Игры и программы MIDP (`.jar`, `.jad`). Обычные `.jar` для компьютера запускаются через Java, как раньше. |
| Symbian и N-Gage | EKA2L1 | Нужна прошивка вашего телефона Nokia. Без неё эмулятор открывается, но программы не запускаются. |
| КПК Windows Mobile и Pocket PC | PocketHLE 0.3.2 | Ранний экспериментальный слой: импорт `.cab` и `.exe` в библиотеку и запуск из неё. |
| Windows Phone 7/8/10 | — | Рабочего эмулятора для Linux нет. Матрёшка честно об этом сообщает. |

Недостающие библиотеки и пакеты Darling ставит служба `matryoshka-compat-setup` при первом подключении к сети после обновления. Пока она не закончила, окно показывает «ещё устанавливается». Журнал: `/var/lib/matryoshka/compat/setup.log`.

### Исправления в Darling

Darling собран из исходников выпуска 0.1.20260608: готовые пакеты проекта сделаны для Ubuntu 24.04 и на Debian 13 не ставятся. При сборке исправлено:

- `libcorecrypto` не экспортировала 18 функций, которые нужны Security.framework (`ccdh_ccn_size`, `cchkdf_extract`, `ccchacha20` и другие). Из-за этого PyObjC и программы, использующие Security, падали при загрузке. После исправления PyObjC загружается и окно Cocoa создаётся.
- Пакет `darling-cli-python2-common` собирался пустым из-за неверного имени файла установки, поэтому не было `libexpat` и Python внутри Darling не мог читать plist. Сообщение авторам: https://github.com/darlinghq/darling/issues/2532
- Сборка на Debian 13: `libtiff-dev` вместо `libtiff5-dev`, `dh_strip` больше не пытается обработать текстовый файл `magic/elf`.
- Матрёшка запускает Darling с отдельной папкой кеша (`~/.local/share/matryoshka/compat/darling-cache`). Без неё fontconfig и Mesa внутри Darling не могли записать кеш и выводили сотни ошибок.

Патчи и рецепты сборки лежат в `packaging/compat/`. Причину чёрных окон Cocoa найти не удалось: Mesa внутри Darling работает (llvmpipe, OpenGL 4.5), окно появляется и управляется оконным менеджером, но картинка в него не выводится. Это остаётся задачей на следующие выпуски.

## Что проверено и что нет

Проверено на сборочной машине с Debian 13 (Mesa 25.0.7, llvmpipe, без видеокарты):

- touchHLE: бесплатная игра Explora-Ball (CC0) открывается через окно Матрёшки, главное меню рисуется в 3D. Родной OpenGL ES 1.1 на виртуальном экране не создался, touchHLE сам перешёл на свой слой GLES1 поверх OpenGL 2, и это сработало;
- FreeJ2ME-Plus: игра SuperTux для J2ME (GPL-2) открывается через окно Матрёшки, меню работает;
- PocketHLE: окно библиотеки открывается;
- EKA2L1: окно эмулятора открывается и просит установить устройство (прошивки у нас нет);
- Darling: `darling shell`, `sw_vers` (macOS 11.7.4), настоящая программа jq 1.8.1 для macOS x86-64 (`--version` и обработка JSON). Окно Cocoa через PyObjC создаётся, но его содержимое чёрное;
- Inferno: собирается, `--version` и список машин (iPhone 6s Plus, iPhone 11) выводятся;
- 23 новых модульных теста распознавания файлов (Mach-O, IPA, MIDlet, CAB и PE для КПК, XAP) успешны;
- пакет собран штатным `make-bundle.sh`.

Не проверено: применение пакета на установленной системе и работа службы установки, игры iOS и Java на настоящей видеокарте, Metal в Darling, программы macOS из `.dmg` и `.pkg`, Symbian с прошивкой, настоящие программы КПК, Inferno с прошивкой.

Подписи `.sig` у этого выпуска нет: проверяйте архив по SHA256 из файла `.sha256`.
