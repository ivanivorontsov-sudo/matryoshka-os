# Матрёшка 18.6.19

> [!CAUTION]
> **Весь код Матрёшки написан ИИ, за исключением сторонних открытых компонентов.** Возможны ошибки. Используйте на свой риск и перед установкой или обновлением делайте резервные копии важных файлов.

Пакет обновления `matryoshka-update-18.6.19.tar.gz` ставится поверх 18.6.3–18.6.18 тем же способом, что и раньше (копия, затем архив). Новый образ ISO в этом выпуске не выкладывается: последний образ остаётся 18.6.18. Выпуск v18.6.18 и все его файлы оставлены.

**После установки системы из образа обязательно обновитесь** до 18.6.19 через «Копия и обновление Матрёшки».

## Zoom: ошибка с длинным кодом при входе по ссылке

Что было: в официальном клиенте Zoom для Linux при входе в конференцию по ссылке появлялась неизвестная ошибка с длинным кодом `100000400` («Присоединитесь к конференции через браузер»). Так было и для неверной ссылки, вместо обычного сообщения Zoom.

Причина: клиент Zoom читает `/etc/os-release`. В Матрёшке там русское имя системы, и из-за этого запрос на вход в конференцию не проходит.

Что сделано: при запуске только процесс Zoom видит исходный Debian-файл `/usr/lib/os-release`. Имя системы в Матрёшке не меняется. Остальные программы и окно «О системе» остаются как были.

С неверной ссылкой Zoom теперь показывает своё обычное окно «Недопустимый идентификатор конференции», а не ошибку с кодом.

## Что проверено и что нет

Проверено на файловой системе образа 18.6.18 с официальным пакетом Zoom 7.2.5 с zoom.us, в графическом сеансе без монитора:

- ссылка `https://…zoom.us/j/…` через обёртку Матрёшки открывает «Недопустимый идентификатор конференции»;
- если эту правку отключить, снова появляется ошибка `100000400`;
- то же после запуска клиента и передачи ссылки уже открытому окну.

Не проверено на железе: живой вход в конференцию, клик по ссылке из браузера.
