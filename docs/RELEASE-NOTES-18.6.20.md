# Матрёшка 18.6.20

> [!CAUTION]
> **Весь код Матрёшки написан ИИ, за исключением сторонних открытых компонентов.** Возможны ошибки. Используйте на свой риск и перед установкой или обновлением делайте резервные копии важных файлов.

Пакет обновления `matryoshka-update-18.6.20.tar.gz` ставится поверх 18.6.3–18.6.19 тем же способом, что и раньше: «Копия и обновление Матрёшки» (сначала резервная копия, затем архив и его SHA256). Новый образ ISO в этом выпуске не выкладывается: последний образ остаётся 18.6.18. **После установки системы из образа обязательно обновитесь** до 18.6.20.

В пакет входит всё из 18.6.19, в том числе исправление Zoom: вход по ссылке без ошибки `100000400`, процесс Zoom видит исходный `os-release` Debian, имя Матрёшки в системе не меняется.

## ИИ-управляющий

- Использует ту же нейросеть, что и Центр (Центр → Защита): одни настройки для антивируса и управляющего. По умолчанию выбран API, как в Центре.
- Понятные сообщения об ошибках: нет сети, отказ соединения, текст ошибки от API. Окно чата не замирает, пока идёт запрос.
- Менеджер моделей: установка среды Ollama и загрузка моделей GGUF с Hugging Face.
- Поиск в интернете для управляющего: Яндекс и Google. Запрос уходит в сеть только по вашей просьбе и после подтверждения. Ключи поиска (если заданы) не показываются и не пишутся в журнал.
- В поиске панели (KRunner): если ничего не нашлось, появляется пункт «Найти».

## ИванКод

Студия запускается через XWayland и не ждёт бумажник KWallet: окно больше не замирает при старте.

## Поддержка программ с других платформ (iOS, macOS и другие)

Подробный план подготовлен (файл `HANDOFF-18.6.20.md` в исходниках): Darling для macOS, touchHLE для старых игр iOS, FreeJ2ME-Plus для Java кнопочных телефонов, EKA2L1 для Symbian, PocketHLE для Windows Mobile. **В этот пакет эти слои ещё не входят**, они будут в следующих выпусках.

## Что проверено и что нет

Проверено:

- 121 модульный тест исходников: 117 успешны, 3 пропущены (нет темы Breeze и архива NDK на сборочной машине), 1 отказ `test_kickoff_keeps_search_for_a_minute` из-за отсутствия собранного дерева образа, к этому выпуску не относится;
- пакет собран штатным `make-bundle.sh`, его состав совпадает по формату с 18.6.19, файлы пакета распакованы поверх файлов пакета 18.6.19 во временной папке без ошибок.

Не проверено: применение на установленной системе, живой рабочий стол, ИИ-управляющий и ИванКод на железе.

Подписи `.sig` у этого выпуска нет: проверяйте архив по SHA256 из файла `.sha256`.
