# Матрёшка 18.6, этап 1: исправления после 18.5

> Перед обновлением сделайте копию системы (шаг 1 в «Копия и обновление Матрёшки») и сохраните важные файлы отдельно. Подробно: [Важно перед установкой Матрёшки](INSTALLATION-WARNING.md).

## Что исправлено

1. **Экран блокировки зависал через раз.** После разблокировки процесс экрана блокировки мог остаться висеть (например, пока ждал сканер отпечатка), и следующая блокировка не могла его запустить заново. Теперь зависший процесс через 1,5 секунды после разблокировки завершается. Кнопки «Перезагрузить» и «Выключить» на экране блокировки больше не просят второго подтверждения.
2. **Камера тормозила ввод пароля.** Раньше на экране входа сначала включалась камера, и только потом проверялся пароль. Теперь введённый пароль проверяется сразу. Для входа по лицу оставьте поле пустым и нажмите Enter.
3. **Отпечаток пальца.** Экран блокировки ждёт палец всё время, пока он открыт. На экране входа палец работает после выхода из сеанса. После загрузки драйвера GXFP5130 служба отпечатков перезапускается. По желанию отпечаток можно использовать вместо пароля в sudo и в окнах администратора (Центр → Вход по отпечатку и лицу).
4. **Экран входа по-русски, кнопки выключения и перезагрузки работают.**
5. **Выход из сеанса закрывает все программы пользователя.** Обновление системы и установка программ, запущенные из Центра, при выходе не обрываются. Программы, оставленные работать в фоне (tmux, nohup), тоже закрываются при выходе.
6. **Клавиши яркости.** Смена схемы горячих клавиш больше не останавливает службу горячих клавиш. Если сочетания яркости оказались пустыми, они восстанавливаются при входе. Если яркость всё равно не меняется, выполните `matryoshka-keys-diag` и пришлите файл `~/matryoshka-keys-diag.txt`.

## Резервные копии и обновление

- Вкладка «Имеющиеся копии» находит все полные копии системы любой давности: в `/.matryoshka-backup` и в папках `matryoshka-backup` на подключённых дисках. Показывает дату, версию Матрёшки, состояние, полный размер и сколько места освободится при удалении (соседние копии делят одинаковые файлы через жёсткие ссылки).
- Копии больше не удаляются автоматически (18.5 при создании новой копии удаляла все, кроме двух последних). Удалить копию можно только кнопкой «Удалить…» с подтверждением и вводом слова УДАЛИТЬ.
- Для обновления можно выбрать существующую проверенную копию этой же системы вместо новой: место под новую копию не нужно. Перед этим рекомендуется «Проверить суммы».
- «Восстановить из неё…» показывает, как восстановить систему из выбранной копии с флешки через F12.
- Если места для новой копии не хватает, программа предлагает открыть список копий.

## Версии пакетов

matryoshka-upgrade 1.1.0, matryoshka-face 1.0.3, matryoshka-gxfp 0.1.5.

## Обновление с 18.5

Поставьте `matryoshka-upgrade_1.1.0_all.deb`, откройте «Копия и обновление Матрёшки», выберите `matryoshka-update-18.6.tar.gz` и перезагрузите компьютер.
