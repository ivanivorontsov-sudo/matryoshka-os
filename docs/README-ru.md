# Матрёшка 18 — документация разработчика

> **Предупреждение для пользователей и тестировщиков:** система продолжает развиваться, поэтому возможны небольшие недоработки. Перед установкой сохраните пользовательские файлы на внешний носитель, тщательно проверьте разметку и форматирование диска и не включайте шифрование без понимания последствий. См. [полное предупреждение перед установкой](INSTALLATION-WARNING.md).

## Сборка образа
- Debian 13 (trixie), live-build. Конфигурация: `config/`. Файлы системы: `config/includes.chroot_after_packages/`.
- Сборка: `sudo lb config && sudo lb build` в каталоге сборки (конфиг синхронизируется rsync из репозитория). Голосовой ввод: `build.sh` кладёт venv Vosk и модель `vosk-model-small-ru-0.22` в `/opt/matryoshka-voice` (в git не хранится).
- Подпись: ключ выпуска Ed25519 `45A2D53B7751F4A8`. Ключ НЕ перегенерируется. Публичная часть: `/usr/share/matryoshka/update-keys/matryoshka-release.gpg`.

## Резервная копия и два варианта загрузки
- `usr/lib/matryoshka/sysbackup.sh`: `plan`, `create same|КАТАЛОГ`, `verify`, `list`, `last-ok`, `restore` (только из живой системы), `find`.
  Копия хранится на том же диске в `/.matryoshka-backup` (rsync с жёсткими ссылками на прошлую копию), плюс таблица разделов (`gpt.bin`), раздел EFI, fstab и `manifest.sha256`. Файл `OK` пишется только после успешной проверки контрольных сумм.
  **Важно:** служебная копия установщика и системные снимки не заменяют отдельную резервную копию всех личных файлов на внешнем носителе. Перед установкой пользовательские данные нужно сохранить отдельно.
  Копия на том же диске НЕ защищает от поломки самого диска. Для этого нужна копия на внешний носитель (`create /путь`).
- Установщик `install-core.sh` до любых изменений сохраняет GPT, разметку и все разделы EFI в `/run/matryoshka-install-backup` с проверкой SHA256SUMS. При ошибке установка прерывается. После установки копирует живую систему в `/matryoshka-live/live`.
- `etc/grub.d/43_matryoshka_live` добавляет в меню GRUB пункт «Матрёшка — живая система (с диска)». Это второй вариант загрузки, независимый от установленной системы.

## Обновление 17.2 → 18 (`matryoshka-upgrade_*.deb`)
1. Шаг 1: проверенная резервная копия (обязательна, не старше 24 ч).
2. Шаг 2: обновление на месте из пакета `matryoshka-update-V.tar.gz` (проверяется sha256). При ошибке выполняется автоматический откат измененных файлов из копии.
3. Если указан ISO, живая система копируется на диск: так появляется пункт живой загрузки, а прошлая версия сохраняется как `live.prev`.
Запуск: «Обновление системы» в меню или `pkexec /usr/lib/matryoshka-upgrade/upgrade.sh ПАКЕТ SHA256 [ЦЕЛЬ] [ISO]`.
Ручной откат: загрузиться в живую систему (пункт GRUB или флешка, клавиша F12/F9/Esc/F8 при включении) и выполнить `sysbackup.sh restore`.

## Лицензия
`matryoshka-license hwid` выдаёт отпечаток оборудования. Выдача ключа: `packaging/license/issue.sh ИМЯ HWID|any`. Ключ — текстовый файл с подписью Ed25519. Проверка: `matryoshka-license status`. Если ключа нет, система работает без ограничений. Защита не абсолютная: открытую систему можно изменить, и подпись лишь подтверждает подлинность ключа.

## Голосовой ввод
Vosk (Apache-2.0), офлайн, русский. Клавиши Meta+H или значок в трее. Текст вставляется через буфер обмена и Ctrl+V (службу ввода `matryoshka-voice-keyd` можно отправить только из активного сеанса). В некоторых терминалах Ctrl+V не вставляет текст, используйте Ctrl+Shift+V.

## Пространственный звук
Готовые наборы EasyEffects (кроссфид и стереобаза): «Пространство-наушники», «Пространство-сильное», «Кроссфид-мягкий». Это НЕ Dolby Atmos.

## Ограничения
- Активаторы не поставляются и не скачиваются.
- Другие архитектуры (ARM): образ собирается только для amd64. ARM-сборка не тестировалась, программы x86 под Wine на ARM не работают без эмуляции (box64 не входит в образ).
- Юридические тексты в установщике (`legal.py`) требуют проверки юристом.

## Android (Waydroid)
Образы LineageOS 20 VANILLA (без GApps) system+vendor x86_64 встроены в `/usr/share/waydroid-extra/images`, поэтому `waydroid init` работает без интернета. Они скачиваются при сборке скриптом `packaging/fetch-waydroid-images.sh` с проверкой sha256 из официального OTA Waydroid. Модуль binder_linux загружается автоматически (`/etc/modules-load.d/matryoshka-waydroid.conf`). APK открываются двойным щелчком.
