Before you install

Prepare to install Matryoshka OS

Installing an operating system can change or erase data on a drive. Use this checklist before starting the Debian 13-based Matryoshka installer.

Read the full installation warning ↗Get release 18.6.18

1. Check the architecture

The Matryoshka OS 18.6.18 ISO targets amd64 / x86_64 computers. An ARM build is not currently listed. Even on a supported architecture, individual Wi-Fi adapters, graphics devices, sensors and other hardware may need additional drivers or configuration.

2. Back up your files

Copy important files to a separate physical drive or a trusted cloud storage service. Open several files from the backup to verify that they can be read. A backup stored on the same drive will not protect you from drive failure or partitioning mistakes.

3. Review the target drive and partitions

Before confirming changes, carefully check the physical drive model and capacity, partition list, filesystems and mount points. Make sure that a partition containing personal files or another operating system will not be formatted accidentally. Stop if you do not understand a setting.

4. Do not enable encryption blindly

Enable disk encryption only if you understand which data will be encrypted and how recovery works. Store the password and recovery key, if provided, separately from the computer. Losing the key may make the data inaccessible.

5. Understand the project status

Matryoshka OS is actively developed. Features may behave differently depending on hardware, drivers and installed applications. Do not assume universal compatibility; read the notes for the exact release you plan to install.

After preparation

Download both ISO parts and the helper join.sh from the Matryoshka OS download page. Use files from the same release and verify checksums from GitHub Releases. Read the official installation warning and project repository.
