Desktop, compatibility and system tools

Matryoshka OS features

A Debian 13 desktop assembled from established open-source projects, with custom configuration and integrations. The components below are not a promise that every app or device will work out of the box.

Desktop and application compatibility

KDE Plasma 6

A modern, configurable desktop environment on Debian 13.

Windows apps with Wine

Run compatible Windows software through Wine. Some apps require extra configuration or may not work.

Android apps with Waydroid

An Android container integration for supported Linux hardware and applications. APK formats and app compatibility vary.

SuperSmart launcher

A custom home screen and search experience with transliteration and keyboard-layout correction features.

Security and network controls

ClamAV and YARA

Tools for scanning files and inspecting suspicious content. Detection is not a guarantee that a file is safe.

OpenSnitch

Application-level network connection monitoring and rules, subject to configuration.

Isolation tools

Firejail and QEMU are available as tools for selected isolation and virtual-machine workflows.

Backup and maintenance

Snapshots

Snapper and Btrfs can provide filesystem snapshots when the system is installed and configured for them.

Backup tools

Restic and rclone support backup and storage workflows, including supported cloud remotes.

Open-source foundations

Matryoshka OS combines Debian and third-party components. Their licences and upstream projects remain applicable.

Compatibility and limitations

Matryoshka OS 18.6.18 is published for amd64 / x86_64 computers. Hardware support depends on Linux kernel drivers, firmware and device-specific configuration. Wine does not run every Windows program, and Waydroid does not support every Android app or device configuration. Review release notes and back up your data before installation.
