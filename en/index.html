What is Matryoshka OS?

Matryoshka OS is an independently configured desktop distribution based on Debian 13 (trixie), built for amd64 / x86_64 computers. KDE Plasma 6 provides the desktop environment. The project integrates selected open-source components with its own configuration, scripts and workflows.

It is not a new Linux kernel or an operating system written entirely from scratch. Windows application support is provided through Wine; Android app support uses Waydroid. Compatibility depends on the application, drivers, hardware and configuration.

Linux desktop

Debian 13 base with KDE Plasma 6 and a configurable desktop experience.

Windows and Android apps

Wine and Waydroid integration for supported applications, with compatibility limitations.

Maintenance and recovery

A collection of tools for file analysis, network control, snapshots and backups.
